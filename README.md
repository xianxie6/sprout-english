# 芽芽英语 Sprout English · 阶段 1 最小可玩版

2–6 岁英语启蒙网页 App（PWA）。**当前为阶段 1 MVP，基本功能已成形，正在做试用前验收；尚未完成家庭试用验收。** 部分阶段 2 功能已提前实现。

规划见 [规划.md](规划.md)，视觉见 [风格样板.html](风格样板.html)，设备检查和家庭观察记录见 [试用验收.md](试用验收.md)。

## 现在有什么

- **内容资源**：7 个主题 70 词（动物农场、好吃的、动物园、玩具、颜色、我的身体、天空和大自然各 10 词）；87 张插画（70 张词图 + 17 张场景/房子/背景图）；514 段配音（每词 7 段，共 490 段，另有 24 段通用语音）；10 段音效与音乐。配音使用 edge-tts，老师 Ava、芽芽 Ana。
- **孩子流程**：开屏 → 小岛 → 每日课程，或进入主题自由探索；找一找、星星反馈与结算。
- **课程和复习**：每天安排最多 3 个新词和 3 个到期复习词；根据首次找对结果安排间隔复习，学习进度保存在当前设备。
- **跟着动**：首页点脚印玩 4 组动物模仿（兔跳、小鸡扇翅、小猫伸展、小马踏步）；先看配音示范，再留 5 秒模仿，由孩子点箭头继续。每日课程也会穿插一个动物动作。重播会重新示范，4 轮后明确结束；不录制或判断孩子动作，也不将计时完成算作词汇掌握。
- **贴纸花园**：见过的词长花苞，在两个不同的日子首次找对后开花；点植物可重听。
- **晚安模式**：回顾今天接触的词、播放晚安音乐，结束后休息到次日；家长可长按月亮唤醒。
- **家长中心**：长按门锁并完成乘法确认后进入，可看学习记录、线下陪玩建议，设置每日时长和背景音乐，打印全部或学过的闪卡。
- **素材验收页**：家长中心可进入 `#/review`，逐词、逐段检查插画和配音。生产构建隐藏开屏的验收链接，开发模式仍显示。

当前还没有录音回放、儿歌和故事。阶段 2 目标是 12 主题 120 词、6 首儿歌，目前已有 7 主题 70 词（后 5 个主题为提前加入的阶段 2 内容）。首页每座小岛放 4 个主题，超过 4 个自动出现第二座岛（同一张图左右翻转），两侧箭头切换。

## 运行

```bash
npm run dev
```

打开 [http://localhost:5190](http://localhost:5190)。同一 Wi-Fi 下，iPad 可打开 `http://<电脑IP>:5190`，用于真实触控和声音检查。

检查生产构建：

```bash
npm run build
npm run preview
```

PWA 的 Service Worker 仅在生产构建启用。**离线采用按访问缓存，并非全包预缓存**：已访问、已缓存的页面和素材可在断网时复用，未访问的语音或图片可能缺失。iPad 局域网 HTTP 访问用于联机检查；离线验收应在支持 Service Worker 的 HTTPS 环境，或测试机的 localhost 上进行。

## 内容流水线

| 步骤 | 命令 | 说明 |
| --- | --- | --- |
| 改内容 | 编辑 `content/words.json` | 词、句子、生图描述都在这里 |
| 生图提示词 | `npm run prompts` | 生成 `prompts/GPT生图提示词.md`，到 ChatGPT 里生成 |
| 导入插画 | `npm run art` | `art/raw/<id>.png` → 抠图、裁切、压缩到 `public/pack/img/`，出 `art/review.png` 总览 |
| 配音 | `npm run audio` | 只补缺的；`--force` 全部重配；`--only cat,dog` 只配这几个 |
| 核对配音 | 见 `scripts/check_audio.py` 顶部 | 语音识别逐条比对文案 |
| 编译 | `npm run pack` | 生成 `public/pack/en/index.json` |

插画按“概念”存（`public/pack/img/`，所有语言共用），配音按“语言”存（`public/pack/en/`）。
